# Come Hungry — A Menu at My Place

A friendly, non-commercial, English-language home dining menu featuring 37 dishes. Visitors can search and filter dishes, pick favorites, and copy or share their wish list. All selections remain in the browser until shared; this is not a restaurant booking system.

## Publish this repository

This repository already contains `index.html` and `.nojekyll` on the `main` branch. To enable the public site, visit **[Settings → Pages](https://github.com/stasboi/home-guest-menu/settings/pages)**, choose **Deploy from a branch**, select **main** and **/(root)**, and click **Save**. The expected public address is **https://stasboi.github.io/home-guest-menu/**.

## About the images

Food photographs are illustrative and are not photos of food prepared by the host. The site looks for photos through the Wikimedia Commons API and links image sources and license details. Initial images use Commons `Special:FilePath` and category-based Unsplash fallbacks. Some sources may be missing, unavailable, blocked, or not visually identical to the named dish. Photos are loaded from the internet rather than bundled with the repository.

## Privacy and accessibility

Guests submit no information to a backend. They must explicitly copy or share their selection. The site is static and works with standard GitHub Pages, without dependencies or a build step.
